# tekne.personal

Desktop, audio, gaming, and homelab service roles. A personal playbook may call a tekne.work role. This collection does not depend on tekne.work.

Depends on `tekne.common`, `amazon.aws`, `ansible.posix`, `community.docker`, and `community.general`.

## Roles

- `bootstrap`
- `gaming`
- `gpu`
- `kde`
- `xfce4`
- `pipewire`
- `onedrive`
- `gerbera`
- `repotekne`
- `hermes`
- `n8n`
